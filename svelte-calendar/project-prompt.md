Goal: Create a fully client side application in Svelte to get calendar data and render it using primarily tui.calendar.

- prefer typescript where possible
- there's no authentication between the svelte front end and teh backend server
- backend server is implemented in emacs lisp
- front end communicates with the backend over websockets.
- To run emacs unit tests you should use `make tests` from the main directory.


If anything is unclear, asking me. Where options exist prefer simplicity.
